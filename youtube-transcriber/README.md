# YouTube文字起こし

YouTubeの動画URLを貼ると、音声を全文テキストにするツールです。`index.html` 1枚だけで動きます（サーバー不要）。

## これまでのツールとの違い

以前のツールは、ツールのサーバーがYouTubeから音声をダウンロードしていたため、YouTubeのボット確認で止まっていました。
このツールは動画のURLをGoogleのGemini APIにそのまま渡し、Google側で動画を読み込んで文字起こしします。サーバーからYouTubeにアクセスしないので、ボット確認で止まりません。

## 使い方

1. **Gemini APIキーを作る（初回だけ）**
   [Google AI Studio](https://aistudio.google.com/apikey) で「APIキーを作成」を押してコピーします。無料で作れます。
2. **ツールを開く**
   下の公開URLを開きます（`index.html` をダウンロードしてダブルクリックしても使えます）。
3. **キーを保存する（初回だけ）**
   「APIキーと詳細設定」にキーを貼って「保存」。キーはそのブラウザの中にだけ保存されます。
4. **URLを貼って「文字起こしを始める」**
   文字が順に表示されます。終わったら「コピー」で台本シートのE列に貼るか、「TXT保存」で保存します。

「時刻を表示」にチェックを入れると、段落ごとに `[MM:SS]` が付きます（コピー・保存にも反映）。
過去の結果は「これまでの文字起こし」に30件まで残ります（そのブラウザの中だけ）。

`gh-pages` ブランチの `youtube-transcriber/index.html` から公開しています。ツールを直したときは、そのファイルも同じ内容に更新してください。

※ このリポジトリは公開設定です。ツールにキーなどの秘密情報は入っていません（キーは各自のブラウザに保存）。

## 仕様と注意

- 対応：通常の動画、Shorts、youtu.be、ライブのアーカイブ。**公開動画のみ**（限定公開・非公開・メンバー限定は不可）。
- 長い動画は15分ずつ自動で区切って続きを取りにいきます。1時間の動画で数分かかります。処理中はページを開いたままにしてください。
- 途中で止まった場合は「続きから再開」で、止まった位置から再開できます。
- 料金はAPIキーの持ち主に請求されます。無料枠ではYouTube動画は1日8時間ぶんまでです。
- モデルは標準で `gemini-flash-latest`（常に最新のFlash）を使います。
- ファイルを直接ダブルクリックで開いた場合、動画の長さが取れず進捗バーが出ないことがあります。文字起こし自体は動きます。

## うまくいかないとき

| 表示 | 対処 |
|---|---|
| APIキーが正しくないか、期限切れ | AI Studioでキーを作り直し、「保存」し直す |
| リクエストが受け付けられませんでした | 動画が公開されているか確認する |
| モデル「…」が見つかりません | 詳細設定のモデル名を、AI Studioに出ている名前に変える |
| 利用上限に達しました | 時間をおいて「続きから再開」。頻繁なら AI Studio で課金を有効にする |
| 著作物の再現と判定されて止まりました | 音楽が中心の動画は書き起こせないことがあります |
